## About

Certified PC-taking-apart enthusiast. Success rate at putting it back together: high-ish. I treat "why is this broken" less like a problem and more like a personal grudge match I refuse to lose.

Big fan of homelabs, hardware, booting random Linux distros off USB sticks like a digital hobo, and letting AI help me dig myself deeper into rabbit holes I definitely didn't need to be in.

Not a dev. Not an engineer. Just a guy Google and I figured it out together.

## What I'm Into

- 🖥️ Building & upgrading PCs
- 🏠 Homelab & self-hosting
- 🐧 Linux distros (mostly on flash drives, not as a daily thing)
- 🔧 Fixing Windows problems nobody asked me to fix
- 🤖 Following AI news like it's a sport
- 🎮 Gaming gear & monitors
- 🧪 Trying random tools just to see what happens

## Rigs

**Main PC** — Ryzen 7 5800X3D · RX 6900 XT · 32GB RAM · Windows 11 / AtlasOS

**Homelab Server** — Ryzen 5 5500 · RTX 3050 · Ubuntu Server · running way too many Docker containers

Also have a ThinkPad for when I need to look responsible.
